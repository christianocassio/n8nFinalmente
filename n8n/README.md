# Pasta do Workflow N8N

Nesta pasta ficará armazenado o arquivo `workflow.json` exportado do N8N.

## Como importar no N8N:
1. Abra sua interface do N8N (Web / Desktop / Local).
2. Vá em **Workflows** > **Import from File...**
3. Selecione o arquivo `workflow.json`.
4. Ative o workflow e configure as credenciais necessárias (caso use nós de IA como OpenAI ou Gemini).
